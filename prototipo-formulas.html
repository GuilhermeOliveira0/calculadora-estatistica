Escolha um estilo para ver todas as fórmulas escritas nele:

Tamanho da amostra · Média

n = (zα/2 · σEm)2
  • n→ tamanho da amostra
  • zα/2→ valor crítico
  • σ→ desvio padrão populacional
  • Em→ erro da média

Tamanho da amostra · Proporção

n = zα/22 · p(1 − p)Ep2
  • p→ proporção (30% = 0,3)
  • 1 − p→ complemento
  • Ep→ erro da proporção

Intervalo de confiança · Média

Em = zα/2 · σn
IC = ( x − Em ; x + Em )
  • x→ média amostral
  • μ→ média populacional
  • s→ desvio amostral (se n > 30)

Intervalo de confiança · Proporção

p = nº de sucessosn
Ep = zα/2 · p(1 − p)n
IC = ( p − Ep ; p + Ep )
  • π→ proporção populacional

Diminuir o erro

novo Em = Emk
novo n = (zα/2 · σnovo Em)2
  • k→ quantas vezes o erro diminui
  • ÷ 2→ amostra 4× maior
