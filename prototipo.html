Fórmula

Passo a passo

Diminuir o erro

α = 0,05  ·  zα/2 = 1,96
Ex.: 2 = erro pela metade

Fórmulas

novo Em = Em atualfator
novo n = (zα/2 · σnovo Em)2
Em

fator

zα/2
valor crítico (depende da confiança)
σ

n
tamanho da amostra

Dica: erro pela metade → amostra 4 vezes maior. O erro cai com a raiz de n, então dividir o erro por k multiplica a amostra por k².

Passo a passo

  1. 95% → α = 0,05 → zα/2 = 1,96Valor crítico tirado da tabela normal
  2. novo Em = 1,8017 / 2 = 0,9009Dividindo o erro atual pelo fator
  3. novo n = (1,96 · 6,5 / 0,9009)²Substituindo na fórmula do tamanho da amostra
  4. novo n = (12,74 / 0,9009)² = (14,1421)² = 200,00Eleva ao quadrado
  5. novo n = 200Arredonda para cima
  6. aumento = 200 − 50 = 150Quantos elementos a mais pesquisar

Resposta

Novo erro0,90exato: 0,9009
Novo tamanho da amostran = 200exato: 200,00
Aumento+1504 vezes a amostra atual

Para reduzir o erro pela metade (de 1,80 para 0,90), a amostra precisa passar de 50 para 200 elementos, ou seja, 150 a mais.
