          Diminuir o erro

          Se eu quiser um erro menor, quantos elementos a mais preciso pesquisar?

          Dados

          Calculado automaticamente: Em = zα/2 · σ / √n
          Ex.: 2 = erro pela metade

          Fórmulas

          Passe o mouse ou toque numa letra para ver o que ela significa.

          novo Em = Emk novo erro = erro atual ÷ k
          novo n = (zα/2 · σnovo Em)2 novo tamanho = (valor crítico × desvio padrão ÷ novo erro)²
          Em
          erro atual da média – calculado com os dados de agora: zα/2 · σ / √n
          k
          fator – quantas vezes queremos diminuir o erro (2 = metade, 3 = um terço)
          zα/2
          valor crítico – número da tabela normal que depende da confiança: 90% → 1,645 · 95% → 1,96 · 99% → 2,575
          σ
          desvio padrão – o quanto os valores variam (pode ser s, se n > 30)
          n
          tamanho da amostra – o novo n é quantos elementos precisaremos pesquisar

          Dica: erro pela metade → amostra 4 vezes maior. Dividir o erro por k multiplica a amostra por k².

            Regras para lembrar

            • Tamanho da amostra: sempre arredonda para cima, nunca para baixo.
            • p desconhecido: use p = 50%, porque p · (1 − p) atinge o máximo (0,25).
            • Se n > 30, pode-se usar o desvio amostral s no lugar de σ.
            • Erro e p em %: converta para decimal antes da conta (5% = 0,05).
            • Quanto maior a confiança, maior a amostra e maior a amplitude do intervalo.
            • Erro dividido por k → amostra k² vezes maior (erro pela metade → amostra 4 vezes maior).
